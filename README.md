# API Data Pipeline using PySpark

## Project Overview

This project demonstrates an end-to-end ETL pipeline that:

- Fetches data from a public REST API
- Stores raw JSON data
- Processes the data using PySpark
- Performs data transformations
- Writes curated data to Parquet
- (Future) Loads data into AWS services such as S3, Glue, and Redshift

## Tech Stack

- Python
- PySpark
- REST API
- JSON
- Parquet
